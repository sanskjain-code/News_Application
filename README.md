# 📰 Newspaper GUI (Tkinter + NewsAPI)

A simple Newspaper GUI application built with **Python Tkinter** that fetches live news headlines using the [NewsAPI](https://newsapi.org/).  
It displays headlines, descriptions, and images in a clean GUI with navigation buttons.

---

## ✨ Features
- Fetches **top headlines** from NewsAPI.
- Displays **title, description, and thumbnail image**.
- **Next/Previous buttons** to navigate between articles.
- Responsive Tkinter GUI with black theme.
